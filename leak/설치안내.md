# 대원 누수알림기 — 설치 안내

전체 흐름

```
[누수알림기(ESP32+압력센서)] ──와이파이──▶ [Firebase DB /leak/{코드}]
                                              │ 알림이 생기면
                                              ▼
                                   [알림 서버(Cloud Functions)]
                                     │                 │
                          고객 폰 푸시 ▼                 ▼ 관리자 폰 푸시
                 [고객앱 nusu] 확인 → 잠금 테스트 → 출동 접수 ──▶ /requests ──▶ [관리앱(주택관리)]
```

- 고객이 출동 접수를 누르면, 기존 접수와 똑같이 `/requests`로 들어갑니다. 관리앱은 고칠 것 없이 그대로 받습니다.
- 접수 메모에는 `[누수알림기 코드] 알림 내용 / 잠금 테스트 결과`가 자동으로 붙습니다.

---

## 1. 한 번만 하는 준비 (PC에서, 약 30분)

### 1-1. Firebase 요금제 바꾸기
- 푸시 알림 서버(Cloud Functions)는 **Blaze(종량제)** 요금제에서만 올릴 수 있습니다.
- Firebase 콘솔 → daewon-booking → 왼쪽 아래 **요금제 업그레이드** → Blaze를 고르고 카드를 등록합니다.
- 장치 수십 대 규모에서는 무료 사용량 안에 들어갈 가능성이 높습니다.
- 그래도 **예산 알림을 월 1만 원**으로 걸어 두세요. 갑자기 요금이 나오는 일을 막을 수 있습니다.

### 1-2. 웹 푸시 키 만들기
1. Firebase 콘솔 → ⚙ 프로젝트 설정 → **클라우드 메시징** 탭으로 갑니다.
2. 아래쪽 **웹 푸시 인증서 → 키 쌍 생성**을 누릅니다. 긴 글자가 하나 생깁니다.
3. Realtime Database → 데이터 화면에서 `config` 아래에 `push` → `vapid` 칸을 만들고, 그 글자를 붙여 넣습니다.

### 1-3. 데이터베이스 규칙 추가
- Realtime Database → **규칙** 탭을 엽니다.
- `leak/database.rules.추가분.json`의 `leak`, `leakIndex`, `leakAdmin` 세 칸을 기존 규칙 안에 추가하고 **게시**를 누릅니다.
- 기존 칸은 지우면 안 됩니다.

### 1-4. 관리 키 정하기
- 데이터 화면에서 `leakAdmin` → `key` 칸을 만들고, 대표님만 아는 긴 비밀번호를 넣습니다.
- 관리 화면에 들어갈 때 이 키를 씁니다. 규칙상 이 칸은 밖에서 읽을 수 없습니다.

### 1-5. 알림 서버 올리기
PC에 **Node.js 20**을 설치한 뒤(nodejs.org), 명령 프롬프트에서 아래를 차례로 입력합니다.

```
npm install -g firebase-tools
firebase login
cd 내려받은폴더\nusu\leak
cd functions && npm install && cd ..
firebase deploy --only functions
```

끝나면 `leakAlert`, `leakOffline`, `leakAdmin` 세 개가 올라갔다고 나옵니다.

## 2. 장치에 프로그램 넣기 (PC에서, 장치마다 한 번)

1. **아두이노 IDE**를 설치합니다(arduino.cc).
2. 파일 → 환경설정 → 추가 보드 관리자 URL에 아래 주소를 넣습니다.
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
3. 보드 관리자에서 **esp32**를 설치합니다.
4. `leak/firmware/nusu_leak/nusu_leak.ino`를 엽니다. `detect.h`도 같은 폴더에 있어야 합니다.
5. 보드는 **ESP32C3 Dev Module**, **USB CDC On Boot: Enabled**로 설정합니다.
6. USB를 꽂고 → 업로드(→ 버튼)를 누릅니다.
7. 시리얼 모니터(115200)를 열면 `코드 ABCDE-FGHJK`처럼 장치 코드가 나옵니다. **장치 옆면에 스티커로 붙입니다.**
   - 스티커 QR 주소는 `https://cdh7657.github.io/nusu/?go=leak&dev=코드10자`입니다. 하이픈은 빼고 씁니다.

배선 (ESP32-C3 SuperMini 기준)

| 압력센서 | 연결 |
|---|---|
| 빨강 +5V | 5V |
| 검정 GND | GND |
| 신호(0.5~4.5V) | 10kΩ → **GPIO3** → 20kΩ → GND |

센서 범위가 1.2MPa가 아니면, 관리 화면에서 고치거나 `cfg/pmax` 값을 바꿉니다.

## 3. 현장 설치 (휴대폰만으로)

### 3-1. 장치 와이파이 연결
1. 장치 전원을 꽂습니다. 처음에는 파란 불이 빠르게 깜빡입니다.
2. 휴대폰 와이파이 목록에서 **DAEWON-LEAK-XXXX**에 접속합니다. 설정 화면이 자동으로 뜹니다.
   - 안 뜨면 크롬에서 `192.168.4.1`을 엽니다.
3. 화면에 **지금 압력**이 2초마다 나옵니다. 여기서 센서가 제대로 붙었는지 확인합니다.
4. 집 와이파이를 고르고 비밀번호를 넣은 뒤 **저장하고 연결**을 누릅니다.
5. 다시 설정하려면 장치의 BOOT 버튼을 5초 누릅니다.

### 3-2. 고객 폰에 고객앱 깔기
1. 고객 폰 크롬에서 `cdh7657.github.io/nusu`를 엽니다(명함 QR도 가능).
2. 더보기 → **앱처럼 쓰기**를 누르면 홈 화면에 아이콘이 생깁니다.
   - 아이폰은 반드시 이렇게 홈 화면에 추가해야 알림을 받을 수 있습니다.

### 3-3. 장치와 고객앱 연결
1. 고객앱 → 더보기 → **누수알림기 → 누수알림기 연결하기**를 누릅니다. 스티커 QR을 찍어도 됩니다.
2. 코드를 넣고, 집을 고르고, **설치 방식**(감압밸브+탱크 / 감압밸브 없음)을 고른 뒤 연결합니다.
3. **이 휴대폰으로 알림 받기**를 누르고 → 허용합니다.
   - 가족 폰도 같은 방법으로 연결하면 같이 받습니다.

### 3-4. 설치 확인
- **잠금 테스트:** 장치 화면 → 잠금 테스트를 누르고, 계량기 밸브를 잠근 채 10분을 기다립니다. "새는 곳이 없어요"가 나오면 정상입니다.
- **감압밸브 잠김 확인 (감압밸브+탱크 방식만):** 수도꼭지를 아주 살짝 틀어 둡니다. 관리 화면 그래프에서 톱니(주황 점)가 생기면 정상입니다. 매끈하면 감압밸브가 새는 것이니 교체합니다.

---

## 4. 관리자 폰

1. 크롬에서 `cdh7657.github.io/nusu/leak-admin.html`을 엽니다.
2. 관리 키를 넣고 → **이 폰으로 알림 받기**를 누릅니다.
3. 크롬 메뉴 → 홈 화면에 추가를 합니다.
4. 모든 장치의 알림이 옵니다. **학습 기간(설치 후 1달)의 미세누수 알림은 관리자에게만** 갑니다.

---

## 판정 기준 (기본값, 관리 화면에서 장치별로 조정 가능)

| 알림 | 조건 | 고객에게 |
|---|---|---|
| 미세 누수(톱니) | 물을 안 쓰는데 1시간 안에 감압밸브가 5번 이상 규칙적으로 채움 | 학습 기간 후 |
| 미세 누수(하강) | 물을 안 쓰는데 30분 동안 0.3bar 넘게 계속 내려감 | 학습 기간 후 |
| 계속 흐름 | 60분 동안 한 번도 정지 압력으로 못 돌아옴 (기본형: 뚝 떨어진 뒤 60분 회복 없음) | 바로 |
| 연결 끊김 | 90분 넘게 장치 소식 없음 | 바로 |

같은 알림은 6시간에 한 번만 보냅니다.
