# 누수감지기 v2 설계안 (보일러실 인입부 · 밸브형) — 2026-11-29

## 1. 한 줄 정의
대원설비가 보일러실 인입부에 시공하는 감지기. 물을 쓸 때만 밸브를 열어 두고, 1시간 안 쓰면 잠가서 3분 압력시험을 한다. 잠긴 동안 수전 열림 파형이 오면 바로 열고, 파형 없이 압력이 빠지면 누수로 보고 잠근 채 알린다.

## 2. 배관 순서
```
[메인밸브] → [스트레이너] → [래칭 솔레노이드 밸브(수동 손잡이)] → [초음파 유량계 DN15] → [압력센서] → 집 안 분기
      └→ 보일러 보충수 배관 (밸브 "앞"에서 분기)
```
- 보일러 보충수를 밸브 앞에서 빼는 것이 필수다. 밸브가 잠겨도 보일러는 물을 받아야 한다(보충수 부족 → 보일러 정지 → 동파).
- 스트레이너는 밸브 앞에 둔다. 이물질이 끼면 밸브가 덜 닫히거나 안 열린다.
- 압력센서는 밸브 뒤(집 쪽)에 둔다. 잠긴 동안 집 안 배관 압력만 봐야 한다.

## 3. 부품 (필요한 것만)
| 기능 | 부품 | 비고 |

| 유량 | DN15 초음파 유량계 RS485/Modbus | 국산 KC 제품 확인 필요. 레지스터 표는 받아서 확인 |

## 4. 동작
| 상태 | 하는 일 |
|---|---|
| 열림 | 유량·파형 감시. 1시간 안 쓰면 잠금 → 압력시험 |
| 압력시험(3분) | 수전 열림 파형 → 바로 열기. 0.15bar 이상 빠지면 → 누수, 잠근 채 알림 |
| 잠금·새지 않음 확인 | 열림 파형 → 바로 열기. 파형 없이 0.3bar 빠지면: 집 비움이면 누수로 잠가 둠, 아니면 열고 "설명 안 되는 흐름"으로 확인 |
| 누수로 잠가 둠 | 하루 1번 다시 알림. 앱 "밸브 열기"로만 열림(2시간 자동잠금 안 함) |

열린 상태 판정:
- 열림 파형 없이 시작된 흐름 5분 → 알림(확인 질문). 12L/분 넘거나 집 비움이면 바로 잠금
- 수전 닫힘 뒤 남은 작은 흐름 3분 → 알림(변기·수전 샘)
- 15L/분 넘는 흐름 3분 → 알림. 밤·집 비움이면 바로 잠금, 낮엔 10분 대답 없으면 잠금
- 계단형 급강하 파형(파손) → 바로 잠금
- 20분(밤 15분) 넘게 계속 흐름 → 알림
- 확인 질문에 대답 없으면 낮 30분·밤 10분 뒤 잠금. "쓰는 중이에요"를 누르면 그 흐름이 멈출 때까지 안 잠금
- 고객이 "아니요, 안 써요" → 바로 잠그고 압력시험

## 5. 고객앱 기능 (index.html에 넣음)
밸브 상태 보기, 밸브 열기, 집 비움, 물 틀어둠(동파 방지용 유량은 누수로 안 봄), 지금 점검, 수전 등록, 알림 확인(쓰는 중/안 써요/출동 접수). 주간 보고는 월요일 9시, 사고는 즉시.

## 7. 남은 문제와 방향
1. **낮 파손 261L**: 욕조 받기와 구분하려고 10분을 기다린 탓. → 수전 등록으로 욕조 유량을 알면 그보다 큰 흐름은 바로 잠그도록 바꿀 수 있음.
2. **파형 기준값(0.012/0.04bar)**: 모형 배관 탄성 가정값에 맞춘 것. 집마다 배관 길이·재질이 달라 설치 때 수전 등록으로 맞춰야 함.
3. **잠긴 동안 열팽창·수축**: 온수 쪽 온도 변화로 압력이 오르내림. 시험 기준(0.15bar/3분)에 걸리는지 실제 배관에서 확인 필요.
4. **밸브 고장(안 열림)**: 열린 뒤 5초에 압력 회복을 확인해서 알림. 수동 손잡이는 반드시 달린 제품.
5. **유량계 Modbus 레지스터·ADS131M04 설정값**: 부품 받고 데이터시트로 확인. 펌웨어에선 서버 cfg로 바꿀 수 있게 해 둠.
